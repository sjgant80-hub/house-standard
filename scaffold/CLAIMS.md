# __TITLE__: the claims, registered before the sealed run

This file is committed, with the seal (`SEAL.json`), before the run is made. The verdicts are worked out by
`src/claims.mjs` from the recorded run, and the bars in that file are the bars below. A claim that fails stays on the
page, failed, in red. No bar is moved after the run.

## The claims

**C1 · The run is whole.** Every problem the seal fixed has a record in the run.

**C2 · It is right more often than it was.** More problems are right after than before.

## What is not claimed

One sealed run is one sealed run. It says nothing about other inputs.
