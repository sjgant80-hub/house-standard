What this does — and doesn't — claim

It is narrow on purpose. It works where truth is machine-checkable: arithmetic, logic, facts cited from a document. Everywhere else it says "I can't tell". That refusal is the product.

Grounded is not proven. An answer cited from a document is only as true as the document. Each page labels which is which.
