What this does — and doesn't — claim

It is narrow on purpose. It works where truth is machine-checkable: arithmetic, logic, facts cited from a document. Everywhere else it says "I can't tell". That refusal is the product.

Grounded is not proven. An answer cited from a document is only as true as the document. Each page labels which is which.

Nothing is claimed early. The retraining loop has run one sealed round: 24.7% → 48.9% right, cold, on 231 unseen problems. One round, one kind of problem. Its own page says where it did not improve.

This page reads; it does not vouch. Each number is read from the page that proves it. The proof is there: the sealed run, the gate, the records you can re-run.

A failed claim stays. The Climb's C8 (each pass squares what is left) failed its bar and is still on its page, in red.

Most of the estate is not on this standard yet. Of 647 older live pages read on 2026-11-25, none meets it. The five builds above, made since, do. The rest come over in order of what is public-facing.
